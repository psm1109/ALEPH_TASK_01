# 나를 설명하는 작은 기록

저를 처음 만나는 분들에게 제가 어떤 사람이고, 무엇을 좋아하며, 어떤 경험을 해왔는지 보여주는 개인 소개 페이지입니다.

> 저는 이론에 머무르기보다 실제 경험을 통해 깊이 배우고 싶은 사람입니다.

[공개 페이지 보기](https://aleph-task-t01.vercel.app/)

## 페이지 구성

- **소개**: 페이지의 대상과 목적, 나를 설명하는 문장을 번갈아 보여줍니다.
- **공개 범위 점검표**: 공개하는 정보와 공개하지 않는 정보를 안내합니다.
- **강점과 취향 세 가지**: 배움을 적용하는 실천력, 신뢰를 만드는 협업 방식, 노래·기타와 여행·등산에 대한 관심을 소개합니다. 각 경험은 요약과 상황·행동·결과로 구성되어 있습니다.
- **저를 움직이는 세 가지 가치**: 건강·자유·신뢰가 나에게 갖는 의미를 설명합니다.
- **저를 이해하는 몇 가지 기준**: 몰입하는 순간, 힘이 빠지는 순간, 사람들과 가까워지는 방식, 알아두면 좋은 점을 담았습니다.

## 주요 기능

| 기능 | 사용 방법 |
| --- | --- |
| 소개 애니메이션 | 정지·재생 버튼으로 문장 전환을 제어합니다. |
| 경험 상세 보기 | 각 카드의 ‘상황·행동·결과 자세히 보기’를 눌러 펼치거나 접습니다. |
| 학습 기록 모달 | ‘학습했던 내용’을 누르면 학습 이미지 6장을 볼 수 있습니다. 이전·다음 버튼 또는 좌우 방향키로 전환합니다. |
| 모달 닫기 | 닫기 버튼, 모달 바깥 배경 클릭 또는 Esc 키로 닫습니다. 닫은 후 실행 버튼으로 초점이 돌아옵니다. |
| 졸업 작품 결과 | Google Drive의 졸업 작품 시연 영상을 새 탭으로 엽니다. |
| 여행 기록 | Notion의 여행 자료를 새 탭으로 엽니다. |
| 나를 이해하는 기준 | 항목별로 펼치거나 접고, ‘모두 닫기’로 이 영역의 항목을 한꺼번에 접습니다. |
| 맨 위로 이동 | 페이지 하단의 ‘맨 위로’ 링크를 사용합니다. |

## 접근성 및 화면 대응

- 제목을 `h1`, `h2`, `h3` 단계로 구성했습니다.
- ‘본문으로 건너뛰기’ 링크와 키보드 초점 표시를 제공합니다.
- 버튼은 Enter·Space로 실행할 수 있으며, 학습 모달 안에서는 Tab·Shift+Tab으로 버튼 사이를 이동합니다.
- 시스템의 ‘움직임 줄이기’ 설정에 대응합니다.
- 화면 너비에 따라 카드와 공개 범위 영역의 배치를 조정합니다.

접근성 기능의 구현 여부와 최종 배포 화면의 검사 결과는 구분합니다. 제출 전에는 실제 공개 페이지에서 두 기준 해상도(1366×768, 1920×1080), 텍스트 대비, 키보드 조작, 링크와 콘솔 오류를 확인합니다.

## 실행 방법

별도의 패키지 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다. 학습 이미지는 아래 폴더 구조를 유지해야 하며, Google Drive와 Notion 자료를 열려면 인터넷 연결이 필요합니다.

```text
T01/
├── index.html       # 페이지 내용과 구조
├── styles.css       # 스타일, 반응형 배치, 애니메이션
├── script.js        # 상세 접기, 애니메이션 제어, 학습 모달
├── images/
│   ├── 1.jpg
│   ├── 2.jpg
│   ├── 3.jpg
│   ├── 4.jpg
│   ├── 5.jpg
│   └── 6.jpg
└── README.md
```

배포할 때는 HTML·CSS·JavaScript와 `images` 폴더를 함께 포함합니다. 이미지 파일이 배포에서 빠지면 학습 모달의 사진이 표시되지 않습니다.

## 페이지에 선언한 공개 범위

**공개하는 정보**

- 강점과 취향 및 관심사
- 저를 움직이는 가치
- 저를 이해하는 몇 가지 기준

**공개하지 않는 정보**

- 실명, 개인 연락처, 상세 거주 위치
- 학교·기관 식별 정보와 개인 계정
- 인증에 쓰이는 정보와 사적인 대화 내용

이 목록은 페이지에 명시한 공개 원칙입니다. 공개 여부를 확인할 때는 본문뿐 아니라 학습 이미지와 연결된 외부 자료도 함께 검토합니다.
